# React + Vite

Weather API App

-Utilizes VS Code, JavaScript, HTML, CSS, and React to execute an up to date and functional weather App
-Provides accurate location/temperature specific reads to give outfit recommendations based on specific criteria
-Allows users to Add Clothing Items with Photos, while being able to select appropriate temperature specificiations for each clothing item

Continued improvements will include:
-Adding more accurate weather photos to match the current time of day/temperatures
-Allows users to edit and update all personal information, including name and avatar photo - More appealing and continually updated interface

-VS Code
